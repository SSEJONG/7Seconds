# 07. MVP Content List

## 1. MVP 카드 수

MVP에서는 8~10종의 카드만 구현합니다.

목표:

- 공격 카드 4종
- 방어/패링 카드 1~2종
- 기동 카드 1종
- 전술/드로우 카드 2종

## 2. 시작 덱 예시

총 12장.

| 카드 | 수량 | 역할 |
|---|---:|---|
| 빠른 베기 | 3 | 기본 공격 |
| 찌르기 | 2 | 긴 리치 공격 |
| 강타 | 1 | 고피해/경직 |
| 패링 | 2 | 방어/반응 |
| 돌진 | 1 | 접근/기동 |
| 전술 재장착 | 2 | 실시간 드로우 |
| 연속 베기 | 1 | 적중 시 드로우 |

## 3. 카드 정의 초안

### 빠른 베기

```text
타입: ATTACK
사용 횟수: 3
피해: 8
경직: 5
특징: 빠르고 안정적인 기본 공격 카드
```

### 찌르기

```text
타입: ATTACK
사용 횟수: 2
피해: 10
경직: 6
특징: 사거리가 긴 공격
```

### 강타

```text
타입: ATTACK
사용 횟수: 1
피해: 22
경직: 20
특징: 느리지만 강한 공격
```

### 패링

```text
타입: DEFENSE
사용 횟수: 2
효과: 0.35초 패링 윈도우 생성
성공 시: 적 경직 +15
```

### 돌진

```text
타입: MOBILITY
사용 횟수: 1
효과: 적 방향으로 빠르게 접근
충돌 시 피해 6, 경직 8
```

### 전술 재장착

```text
타입: TACTIC
사용 횟수: 1
효과: 카드 1장 실시간 드로우 후 즉시 장착
피해 없음
```

### 연속 베기

```text
타입: ATTACK
사용 횟수: 2
피해: 6
경직: 4
효과: 적중 시 카드 1장 실시간 드로우, 카드당 1회만 발동
```

### 시간 벌기

```text
타입: TACTIC
사용 횟수: 1
효과: 액션 시간 +1.0초
단점: 피해 없음
```

선택 카드입니다. 액션 시간 증가와 적 확장 시퀀스 테스트용으로 유용합니다.

## 4. MVP 적: 검투병

### 기본 스펙

```text
HP: 120
경직 임계치: 30
주요 행동: 접근, 빠른 공격, 돌진 공격, 강공격, 방어
```

### 코어 시퀀스

```text
0.0초 접근
1.2초 빠른 공격
2.4초 횡이동
3.5초 돌진 공격
5.2초 강공격
6.8초 방어 자세
```

### 확장 시퀀스

```text
7.3초 재접근
8.3초 빠른 공격
9.0초 빠른 공격
10.2초 후퇴
11.0초 방어 자세
```

## 5. 테스트 가능한 빌드 맛

MVP에서 확인해야 하는 재미:

```text
0. 전투 1판이 여러 턴 이어지고, 7초마다 멈춰 카드를 다시 고를 수 있는가? 승/패까지 도달하는가?
1. 카드가 곧 액션 버튼처럼 느껴지는가?
2. 기본 공격 없이도 공격 카드로 전투가 성립하는가?
3. 기본 회피 덕분에 손패가 나빠도 억울하지 않은가?
4. 패링 카드가 있을 때 적 공격을 받아치는 맛이 있는가?
5. 전술 재장착/연속 베기로 실시간 드로우가 연결되는가?
6. 시간 벌기로 7초 이후 적 확장 시퀀스를 볼 수 있는가?
```
