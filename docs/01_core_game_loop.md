# 01. Core Game Loop

## 0. MVP가 의미하는 “한 판”

- **한 판 = 전투 1회** (적 1명, 시작 HP·덱으로 한 번 맞붙음).
- **한 판 안에는 턴이 여러 번** 반복된다. 7초만 하고 끝나는 **단일 턴 프로토타입은 MVP가 아니다**.
- **MVP 완료 조건**: 그 전투에서 **승리**(적 HP 0) 또는 **패배**(플레이어 HP 0)까지 도달.

```text
전투 1판
  └─ 턴 1: [정지·계획] → [7초 실시간] → [정산]
  └─ 턴 2: [정지·계획] → [7초 실시간] → [정산]
  └─ …
  └─ 승리 또는 패배
```

## 1. MVP 전체 흐름

MVP는 **적 1명과의 전투 한 판**을, **여러 턴**을 거쳐 승리/패배까지 플레이하는 구조입니다.

```text
게임 시작
→ 전투 초기화 (1판 시작)
→ 플레이어/적 생성
→ 시작 덱 셔플
┌─ 턴 루프 (승패 전까지 반복) ─────────────────┐
│  → 계획 단계 (게임 시간 정지)                 │
│  → 액션 페이즈 (실시간, 기본 7초)             │
│  → 턴 정산                                   │
│  → 승패 체크 → 계속이면 다음 턴              │
└──────────────────────────────────────────────┘
→ 승리 또는 패배 (전투 종료)
```

## 2. 전투 상태

전투는 아래 상태를 가집니다.

```text
INIT
PLAN_PHASE
ACTION_PHASE
RESOLVE_PHASE
VICTORY
DEFEAT
```

### INIT

- 플레이어 생성
- 적 생성
- 덱 생성 및 셔플
- 드로우 pile / 버림 pile 초기화
- 턴 카운트 1로 설정

### PLAN_PHASE

플레이어가 이번 턴의 액션 세트를 확정하는 단계입니다.

**시간 처리 (MVP 필수)**:

- 플레이어 **이동·회피·카드 사용 불가** (`can_control = false`).
- **7초 액션 타이머는 진행하지 않는다** (액션 페이즈가 아님).
- 구현: `Engine.time_scale`은 UI 입력을 위해 1을 유지하고, 조작·타이머로 정지를 표현한다.
- UI로 카드 드로우·교체·슬롯 장착·「액션 시작」 입력만 받는다.
- 이전 턴의 7초 액션 페이즈가 끝난 뒤 **반드시** 이 단계로 돌아온다 (전투가 끝나지 않았을 때).

순서:

```text
1. 카드 5장 드로우
2. 적 의도/시퀀스 예고 표시
3. 플레이어가 카드 교체 여부 선택
4. 각인/패시브 카드 자동 발동, MVP에서는 선택 구현 가능
5. 남은 카드들을 액션 슬롯에 장착
6. 액션 페이즈 시작 입력 대기
```

MVP에서는 각인 카드를 구현하지 않아도 됩니다. 구현한다면 자동 발동 후 슬롯에 장착하지 않습니다.

### ACTION_PHASE

실시간 조작 단계입니다. **게임 시간이 다시 흐른다.**

기본 규칙:

```text
기본 시간: 7초
플레이어는 이동/기본 회피 가능
공격/패링/기술은 카드 슬롯으로만 가능
적은 현재 액션 시간에 맞는 시퀀스 수행
실시간 드로우 발생 시 새 카드 즉시 장착
```

종료 조건:

- 액션 시간이 0이 됨 → **턴 종료** 후 정산·계획 단계로 (전투 지속 시)
- 플레이어 HP가 0 이하 → **즉시 패배**, 전투 종료
- 적 HP가 0 이하 → **즉시 승리**, 전투 종료

### RESOLVE_PHASE

액션 페이즈 종료 후 정산합니다. MVP에서는 짧게 처리한 뒤 곧바로 **다음 턴의 PLAN_PHASE** 또는 **VICTORY/DEFEAT**로 이어집니다.

```text
1. 사용/미사용 장착 카드 버림 pile로 이동
2. 임시 슬롯 카드 정리
3. 지속 효과 턴 감소
4. 승패 체크
5. 전투가 끝나지 않았으면 다음 턴 시작
```

### VICTORY

- 적 HP가 0 이하
- 승리 UI 표시
- MVP에서는 재시작 버튼 제공

### DEFEAT

- 플레이어 HP가 0 이하
- 패배 UI 표시
- MVP에서는 재시작 버튼 제공

## 3. 턴 기본값

| 항목 | 값 |
|---|---:|
| 기본 드로우 | 5장 |
| 카드 교체 | 턴당 1회 |
| 교체 방식 | 원하는 수만큼 버리고 같은 수만큼 드로우 |
| 기본 액션 시간 | 7초 |
| 기본 액션 슬롯 | 5개 |
| 임시 슬롯 | 최대 2개 |
| 기본 이동 | 가능 |
| 기본 회피 | 가능 |
| 기본 공격 | 없음 |
| 기본 패링 | 없음 |

## 4. 한 턴 예시 (전투 1판 안의 1턴)

```text
턴 1 — [시간 정지] 계획
→ 카드 5장 드로우
→ 적 의도: 접근 → 빠른 공격 → 돌진 공격
→ 플레이어가 카드 2장 교체
→ 최종 카드 5장을 액션 슬롯에 장착
→ 「액션 시작」 입력

턴 1 — [실시간] 액션 페이즈
→ 7초 타이머 시작, 게임 시간 재개
→ 플레이어 이동·회피·카드 사용
→ 적 시퀀스 수행
→ 시간 0 → 턴 종료

턴 1 — 정산
→ 슬롯 카드 버림, 승패 미달 시

턴 2 — [시간 정지] 계획 (전투 계속)
→ 다시 카드 5장 드로우 …
→ (반복)

… 적 HP 0 → 승리 / 플레이어 HP 0 → 패배 (전투 1판 종료)
```

## 5. 전투 1판 예시 (여러 턴)

```text
전투 시작 (플레이어 100 HP, 적 120 HP)
턴 1~3: 위 사이클 반복, HP만 감소
턴 4: 적 처치 → VICTORY, 전투 종료
```

또는 중간 턴에서 플레이어 HP 0 → DEFEAT, 전투 종료.
