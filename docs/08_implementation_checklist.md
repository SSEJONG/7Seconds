# 08. Implementation Checklist

## 1. 1차 목표

**적 1명과의 전투 1판**(여러 턴)이 다음 순서로 정상 동작해야 합니다.

> ❌ 잘못된 MVP: 7초 한 번·카드 한 번만 하고 종료  
> ✅ 올바른 MVP: 턴 루프 반복 후 승리 또는 패배

```text
전투 1판 시작
┌─ 턴 반복 (승패 전까지) ─────────────────────────┐
│  [시간 정지] 카드 5장 드로우 → 교체 → 슬롯 장착   │
│  [실시간] 7초 액션 페이즈 — 플레이어·적 행동     │
│  [정산] 턴 종료, 카드 버림                       │
└──────────────────────────────────────────────────┘
→ 적 처치 시 승리 (전투 종료)
→ 플레이어 사망 시 패배 (전투 종료)
```

## 2. 구현 순서 추천

### Step 1. 전투 상태 머신

- [x] INIT
- [x] PLAN_PHASE (게임 시간 정지)
- [x] ACTION_PHASE (실시간, 기본 7초)
- [x] RESOLVE_PHASE
- [x] VICTORY
- [x] DEFEAT

완료 조건:

- 버튼 또는 자동 흐름으로 상태가 전환된다.
- `ACTION_PHASE` 종료 후 승패가 없으면 `PLAN_PHASE`로 돌아가 **2턴 이상** 이어질 수 있다.
- `PLAN_PHASE`에서 월드 시간이 멈추고, `ACTION_PHASE`에서만 시간이 흐른다.

### Step 2. 플레이어 이동/회피

## 3. MVP 완료 기준

아래가 가능하면 MVP 1차 완료입니다.

```text
1. 게임을 시작하면 적 1명과의 전투 1판이 시작된다.
2. 계획 단계에서 시간이 멈추고, 턴마다 카드 5장을 뽑는다.
3. 카드를 교체할 수 있다.
4. 손패가 액션 슬롯으로 장착된 뒤 7초 액션 페이즈가 시작된다.
5. 7초가 끝나면 다시 시간이 멈추고 다음 턴 계획이 가능하다 (승패 전까지 반복).
6. 플레이어는 액션 페이즈에서만 기본 이동/회피가 가능하다.
7. 공격은 카드로만 가능하다.
8. 패링은 카드로만 가능하다.
9. 액션 페이즈 중 카드 효과로 새 카드를 드로우하고 즉시 장착할 수 있다.
10. 적은 턴당 7초(또는 연장된) 코어/확장 시퀀스를 수행한다.
11. 여러 턴을 거쳐 적을 처치하면 승리한다.
12. 여러 턴 중 어느 때든 플레이어 HP가 0이면 패배한다.
```
