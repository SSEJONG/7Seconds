# 02. Player Controls and Action Phase

## 0. 시간 흐름 (전투 1판 기준)

| 단계 | 게임 시간 | 플레이어 조작 |
|------|-----------|----------------|
| 계획 단계 (`PLAN_PHASE`) | **조작 정지** | 카드 드로우·교체·슬롯 장착만 — **Enter / [액션 시작] 후** 이동 가능 |
| 액션 페이즈 (`ACTION_PHASE`) | **실시간** | 이동·기본 회피·슬롯 카드 사용 |
| 턴 정산 (`RESOLVE_PHASE`) | 조작 정지 | UI만, 곧 다음 턴 계획 또는 승패 |

7초가 끝나면 액션 페이즈가 끝나고, **다시 시간이 멈춘 계획 단계**로 돌아간다. 이 사이클은 **승리/패배 전까지** 반복된다 (한 턴만으로 끝나면 안 됨).

## 1. 플레이어 기본 조작

MVP에서 플레이어는 **1인칭 시점**으로 3D 공간에서 자유 이동합니다.

## 2. 기본 제공 행동

| 행동 | 기본 제공 | 설명 |
|---|---:|---|
| 이동 | O | WASD 또는 왼쪽 스틱 |
| 카메라 | O | **1인칭** 마우스 시점(좌우=몸 회전, 상하=시야) |
| 락온 | X | MVP 제외 |
| 회피 | O | 기본 생존 수단 |
| 공격 | X | 카드 필요 |
| 패링 | X | 카드 필요 |
| 가드 | X | 카드 필요 |
| 특수 이동 | X | 카드 필요 |

핵심 원칙:

> 이동과 최소 회피는 기본 조작, 전투 행동은 카드 조작.

## 3. 기본 회피

기본 회피는 손패가 나빠도 최소 생존을 가능하게 하는 안전장치입니다.

권장 MVP 수치:

| 항목 | 값 |
|---|---:|
| 회피 쿨다운 | 1.0초 |
| 무적 시간 | 0.25초 |
| 이동 거리 | 짧음~보통 |
| 후딜 | 0.2초 |
| 저스트 회피 보상 | MVP에서는 없음 또는 시간 +0.1초 디버그 |

기본 회피는 강력한 보상 없이 피해를 피하는 용도입니다.

## 4. 액션 페이즈 기본 규칙

```text
계획 단계에서 「액션 시작」 후에만 진입
기본 액션 시간: 7초 (이 구간만 게임 시간 흐름)
시작 시 액션 슬롯 활성화
시간이 0이 되면 해당 턴 종료 → 정산 → (전투 지속 시) 계획 단계로 복귀
전투 중 시간 증가/감소 가능
```

플레이어는 액션 페이즈 중 다음 행동을 할 수 있습니다.

```text
이동
기본 회피
액션 슬롯 카드 사용
```

## 5. 손패 카드 입력 (MVP 구현)

PC · **1인칭 액션** 기준. 손패 전체가 이번 턴 액션 풀이며, **한 번에 한 장만** 사용합니다.

| 입력 | 기능 |
|---|---|
| WASD | 이동 |
| Mouse | 시점(액션 페이즈) |
| Space | 기본 회피 |
| **마우스 휠** | 손패에서 **선택 카드** 변경 (▶ 표시) |
| **마우스 좌클릭** | 선택 중인 카드 **1회 사용** (남은 횟수 -1) |
| 계획 단계 UI | 카드 클릭 → 교체 확정 |

> 기획 초안의 슬롯 1~5 키 방식은 MVP 코드에서 **손패+휠+좌클릭**으로 대체했습니다. 임시 슬롯·실시간 드로우 장착은 이후 단계.
| Q/E | 임시 슬롯 선택 또는 사용, MVP에서는 선택 |

MVP에서는 기본 슬롯 5개를 우선 구현하고, 임시 슬롯은 6/7번 키로 처리해도 됩니다.

## 6. 카드 액션 사용 공통 규칙

카드 액션은 카드마다 다릅니다.

공통 필드:

```text
사용 횟수
선딜
판정 시간
후딜
피해량
경직량
캔슬 가능 여부
드로우 효과 여부
시간 증감 효과 여부
```

## 7. 액션 캔슬 MVP 규칙

MVP에서는 복잡한 캔슬을 줄입니다.

권장 규칙:

```text
카드 액션 시작 후 후딜이 끝날 때까지 같은 카드 재사용 불가
회피는 대부분의 후딜을 캔슬 가능
강공격 카드만 회피 캔슬 불가 또는 제한
```

간단 구현안:

- 카드 사용 중 `isActionLocked = true`
- 회피 입력 시 `canDodgeCancel == true`인 액션만 중단 가능
- MVP에서는 모든 공격을 회피 캔슬 가능하게 시작해도 됨

## 8. 손맛·타격감 조정 (구현됨)

기획자가 에디터에서 바꿀 수 있는 항목은 **`docs/09_player_feel_tuning.md`** 와 `resources/combat/default_player_feel.tres` 를 참고합니다.

## 9. 액션 시간 변화

액션 시간은 카드/효과로 늘거나 줄 수 있습니다.

```text
currentActionTimeRemaining += delta
```

주의:

- 0 이하가 되면 즉시 액션 페이즈 종료
- 증가 시 적은 확장 시퀀스로 이어감
- UI에 남은 시간 표시 필수
