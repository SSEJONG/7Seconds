# MVP 문서 세트: 3D 액션 덱빌딩 로그라이크 프로토타입

## 목적

이 문서 세트는 **적 1명과의 전투 1판(여러 턴)**을 끝까지 플레이할 수 있는 MVP를 구현하기 위한 최소 시스템 정의서입니다.

핵심 목표는 다음입니다.

- **한 번의 전투** 안에서 **턴이 반복**되고, 승리 또는 패배로 전투가 끝남
- 7초 액션 페이즈 종료 후 **게임 시간이 멈추고** 다시 카드(계획)를 정할 수 있음
- 카드가 이번 턴의 액션 세트가 되는 전투 구조 구현
- 기본 이동/기본 회피 + 카드 기반 공격/패링/기술 구현
- 액션 페이즈 중 실시간 드로우와 즉시 장착 구현
- 적 1명의 액션 시퀀스 구현
- 전투 시작부터 승리/패배까지 한 판 완료 가능

## MVP 범위 (반드시 구분)

| 구분 | MVP에 해당? | 설명 |
|------|:-----------:|------|
| **전투 1판** (적 1명, 승/패까지) | ✅ | 게임 시작 → 같은 전투 안에서 턴 반복 → 승리 또는 패배 |
| **턴 1회만** (7초 한 번하고 종료) | ❌ | 잘못된 MVP. 최소 2턴 이상 반복·정산이 가능해야 함 |
| **로그라이크 런** (맵·여러 방·보상) | ❌ | MVP 이후 확장 |

한 판(전투)의 한 사이클:

```text
[시간 정지] 계획 단계 — 카드 드로우·교체·슬롯 장착
    ↓
[실시간] 액션 페이즈 — 기본 7초, 이동·회피·카드 사용
    ↓
[정산] 턴 종료 — 카드 버림, 승패 확인
    ↓
생존 시 → 다음 턴(다시 계획 단계) / 사망·처치 시 → 전투 종료
```

## 구현 범위

MVP는 로그라이크 **전체 런**이 아니라, **적 1명과의 전투 한 판(여러 턴)**을 목표로 합니다.

포함:

- 플레이어 1명
- 적 1명
- 카드 8~10장
- 시작 덱 10~12장
- 턴 기반 계획 단계
- 실시간 액션 페이즈
- 기본 이동/기본 회피
- 카드 액션 슬롯
- 실시간 드로우/즉시 장착
- 적 1명의 코어/확장 시퀀스
- 승리/패배 처리
- 간단한 디버그 UI

제외:

- 맵 선택
- 보상 선택
- 유물 시스템
- 복수 적 전투
- 캐릭터 성장
- 저장/로드
- 완성형 아트/사운드
- 복잡한 상태이상

> 적 1명과의 전투 한 판에서, 손패가 이번 턴의 액션 세트가 되고 7초 실시간 전투 후 시간이 멈춰 다시 카드를 고르며, 승리·패배까지 턴이 반복되는 3D 액션 덱빌딩 전투.
